# Maestro Illustrator 功能与使用说明

版本基线：工作台 v12（2026-09-22）。适用于已经完成虚拟筛选、对接和 MM/GBSA 评分后的化合物复核与采购筛选。

## 1. 程序用途

Maestro Illustrator 将分子结构相似性、骨架分类、评分、三维结合姿态和蛋白–配体互作放在同一工作台中，帮助用户从化合物库中人工筛选初筛候选，数量默认不限，也可自定义上限。

程序读取已有对接姿态与评分。它不执行新的对接，也不计算 MM/GBSA；聚类结果不能替代实验活性验证。

## 2. 功能总览

| 模块 | 功能 |
|---|---|
| 数据导入 | CSV、TSV、SMI/TXT、SMILES 粘贴、SDF、MAE/MAEGZ；可单独载入 PDB 受体 |
| 数据检查 | 无效结构、重复结构、多片段、未指定立体中心、缺失或非数字评分检查 |
| 结构聚类 | 完整分子、Murcko 骨架、通用 Murcko 骨架；Morgan 指纹、Tanimoto 相似度、Butina 聚类 |
| 分析范围 | 按 MM/GBSA、Docking 或原始顺序保留前 N 个有效记录并重新聚类，可恢复全量 |
| 可视化 | 二维分子结构、结构簇、化学空间投影、评分分布、表格和分子详情联动 |
| 三维复核 | 原始配体与受体坐标、口袋范围、蛋白丝带/主链、口袋表面、邻近残基、距离与景深裁切 |
| 互作分析 | 本机 Schrödinger 接口识别氢键、卤键、盐桥、π–π 和 π–阳离子互作；项目缓存可离线阅览 |
| 残基筛选 | 指定一个或多个残基、互作类型、任一（OR）或全部（AND）规则，筛选有/无/未确定互作 |
| 比对与突变复核 | 多受体序列比对与互作保守性辅助查看；野生型接触和氨基酸性质层面的单点突变复核 |
| 采购决策 | 人工加入、移除、排除、备注；数量默认不限，可自定义上限，同一规范结构不能重复采购 |
| 项目管理 | 本机多项目、30 分钟定时保存、离站未保存提示、项目 JSON 导出与重载 |
| 结果导出 | 采购 CSV、当前分析范围的完整分析 CSV、项目 JSON、姿态 SDF、受体 PDB、互作表、图片及 PyMOL 场景 |

## 3. 两种运行方式

### 在线工作台

打开现有工作台。二维结构分析在浏览器中完成；读取本机结构和重新计算原生互作时，需本机服务运行。网页无法在每次访问时绕过浏览器权限自动启动任意本地程序。

### 本地源码版本

安装 Node.js 22.13 或更高版本，以及 Git。在源码目录打开终端：

```powershell
npm ci
npm run dev
```

浏览器打开 `http://localhost:3000/`，保持终端运行。`npm ci` 使用锁文件安装一致的依赖；第一次运行需要网络。

若需要 MAEGZ 原生解析或互作重算，另外使用已安装、已授权的 Schrödinger 自带 Python 启动服务。可在第二个 PowerShell 窗口执行：

```powershell
& '你的Schrodinger安装目录\run.exe' python3 scripts/schrodinger_bridge.py --connection-file scripts/schrodinger-connection.json
```

网页会自动探测 `127.0.0.1:8765`。首次浏览器提示本地网络访问时，根据需要允许。不要把临时连接 JSON 上传或分享。一般不需要手动反复选择连接文件。

纯 SMILES 的二维分析和已经保存的互作缓存，不要求安装 Schrödinger。该软件和许可证不随本项目提供。

## 4. 导入化合物

### CSV / SMILES

点击“导入分子”，选文件或粘贴内容，解析数据列并确认映射，再开始结构分析。只有 SMILES 必需。

```csv
id,smiles,docking,mmgbsa,supplier,catalog_id
CMP-001,CC(=O)Oc1ccccc1C(=O)O,-8.2,-42.1,Vendor,CAT001
CMP-002,CCOc1ccccc1,-7.4,-35.6,Vendor,CAT002
```

- Excel 表格应另存为 CSV UTF-8；表头须唯一。
- 评分列可缺失；0 是有效值。程序不从分子结构推测缺失评分。
- 重复 ID 保留独立记录；重复规范结构会标记。
- 无效 SMILES 不参加分析，应在“数据检查”中复核。
- 默认演示数据包含模拟评分，不能直接用于真实采购。

### MAE / MAEGZ / SDF

原生服务连接后导入文件，可读取结构坐标和属性，识别受体与配体，并提取已有 Docking / MMGBSA dG Bind 等字段。若没有 MM/GBSA 属性，页面显示缺失；请导入确实包含评分的 Prime 结果文件或带对应评分的表格。

没有受体时，可能文件仅包含配体；可点击“单独载入受体”。受体和配体必须在同一坐标系，程序不自动做结构叠合。多个受体时，请明确选择对应结构。

无原生服务时，浏览器提供有限的 Maestro 解析支持；不保证支持所有压缩姿态或专有属性格式。复杂 MAEGZ 优先通过原生服务读取。

## 5. 先保留前 N 个，再分析

左侧“聚类参数”中展开“保留前 N 个分子进行分析”：

1. 选择 MM/GBSA、Docking 或原始顺序。
2. 输入 N，例如 500。
3. 点击“保留前 N 个并重新分析”。

取样基于完整项目中的有效结构，不受当前列表的搜索、簇或互作筛选影响。两种评分均按数值从低到高排列；缺失分数不参与对应评分排名，同分按原始顺序取舍。N 按记录计数，包括重复结构；N 超过可用记录数时保留全部可用记录。

只有保留范围参与本次聚类和投影。原始数据、姿态、互作、备注及采购决策保留；范围外候选仍计入候选总数并出现在采购导出中，但不分配本次聚类编号。“恢复全部分子分析”可返回全量。

## 6. 如何选聚类参数

| 参数 | 含义与使用建议 |
|---|---|
| 完整分子 | 比较整体结构指纹，包括侧链变化 |
| Murcko 骨架 | 保留环和连接环的链，移除外围侧链；实现还保留骨架上的末端双键原子 |
| 通用 Murcko | 在骨架基础上将原子视作碳、键视作单键，更强调拓扑连接 |
| Morgan 半径 | 指纹关注的局部结构邻域范围；不同半径的阈值不可直接等同 |
| 指纹长度 | 1024 / 2048 / 4096 位；比较不同结果时应固定设置 |
| 考虑手性 | 决定指纹是否包含手性信息；规范 SMILES 去重仍保留已指定立体化学 |
| Tanimoto 阈值 | 0–1；通常越高越严格。可从 0.50–0.65 开始，结合代表结构调整 |

0.30–0.45 可用于粗分家族，0.65–0.80 查看较近类似物，0.85–0.95 更严格。这些仅是探索起点，不能跨不同骨架和指纹设置直接比较。无环分子以完整结构参与。

骨架模式先对唯一骨架聚类，再映射回各分子。Butina 成员与簇中心达到阈值，不保证簇内任意两个成员都达到该阈值。候选数量和结构簇数相互独立，不需要强行调成相同数量。

散点图采用 FastMap 距离投影，仅用于导航；真实相似性由原指纹计算，而不是二维图上的视觉距离。

## 7. 指定残基互作筛选

展开化合物列表上方的“按指定残基互作筛选”，输入完整残基标识，例如：

```text
A:ARG609, A:ARG758
```

输入非空残基时，默认启用“具有互作（应用到列表）”。

| 选项 | 意义 |
|---|---|
| 任一残基有互作（OR） | 至少与输入残基中的一个具有所选类型互作 |
| 全部残基均有互作（AND） | 与每个输入残基都至少具有一个所选类型互作 |
| 不具有互作 | 对上述规则取否定；AND 的否定表示“并非全部满足”，不等于“两个都没有” |
| 未确定 / 待计算 | 没有计算结果、缺失姿态或相关互作类型计算失败；不当作阴性 |
| 全部（仅统计，不筛选） | 显示统计，但列表保留当前其他条件下的全部记录 |

“当前范围：有 X · 无 Y · 未确定 Z”是应用互作筛选前、其他条件下的分布。其下状态行明确给出“列表保留 X / 总数”；可点击“仅显示有互作”等快捷按钮，列表和分页同步更新。

例如在同一项目中先保留 MM/GBSA 前 500 个，再要求 ARG609 和 ARG758 全部具有互作，若统计为有 80、无 420，列表应保留 80 条。这个数量只适用于对应数据、受体、互作缓存和类型设置。

原生氢键、卤键、盐桥、π–π、π–阳离子均可单独选择；附加几何近接不纳入这些筛选。空链使用 `_`。请从建议列表选择真实残基编号。

点击“计算待筛选分子的缺失互作”可以批量补齐结果，支持停止。计算范围受分数、结构簇、搜索和采购状态影响，不受互作结果筛选限制。

## 8. 对接姿态和口袋复核

选中分子后点击“查看对接姿态 · 3D”。

- 预览范围：口袋与蛋白背景、仅邻近口袋、完整复合物/蛋白、仅配体。
- Cartoon：柔和丝带、纤细主链、经典丝带。
- 邻近半径控制显示哪些口袋残基及表面，不改变原生互作判据。
- 口袋可显示分子表面或溶剂可及表面，透明度可调。
- 可显示棒状残基、残基标签、互作虚线与距离。
- 点口袋原子、残基标签、下方残基按钮或互作明细的受体端点，可放大定位；“重置取景”返回配体。
- 标签随视角和缩放更新，遵循景深裁切；为便于点选，文字不会被表面完全遮挡。
- 正交/透视和景深裁切厚度可用于减少遮挡。

互作类型开关联动虚线与明细。氢键距离可能是 H···受体原子的距离，π 互作通常是环/电荷中心距离，不应都按重原子间距离解释。附加几何近接只表示特定重原子距离较近，不等同于氢键。

## 9. 序列比对与单点突变复核的边界

可以导入额外受体，选择一个或多个比较对象辅助查看互作残基的序列保守性。当前结构自身不会作为比较对象；没有其他受体时显示缺失结果。应优先使用明确对应的单链结构，并人工复核残基映射；多链、缺失残基或编号差异可能影响解释。

“单点氨基酸突变分析”目前提供野生型现有互作和氨基酸性质的辅助复核，**没有构建突变结构、优化侧链或计算突变 ΔΔG**。不能把该面板作为突变后结合能力的预测结果。

## 10. 采购、保存与导出

初筛候选需人工选择，数量默认不限，可自定义上限；可排除分子并填写复核备注。同一规范结构只允许保留一个采购记录。供应商、货号、盐型、立体化学、纯度和供货仍需独立确认。

项目保存在当前浏览器、当前网站来源的 IndexedDB 中；localhost 和在线网站的项目库彼此独立，不同浏览器也不共享。清除网站数据或使用无痕模式可能导致本机项目丢失。

有更改时每 30 分钟尝试自动保存，也可随时“保存到本机”。离站提示受浏览器支持和后台调度限制，不能代替主动保存。重要阶段建议同时下载项目 JSON，作为跨浏览器、跨设备的备份。

项目 JSON 包含原始输入、已应用参数、分析范围、采购决策、结构和缓存互作，不保存本机服务令牌。恢复后缓存可直接显示；重算时原生服务可从已保存的原子、坐标、键和电荷重建结构。

导出采购 CSV 包含所有已选候选；完整分析 CSV 对应当前分析范围，不等同于当前互作过滤后的列表。导出前应确认所选范围和文件用途。

## 11. 常见问题

| 现象 | 排查方法 |
|---|---|
| MM/GBSA 显示横线 | 检查原文件是否真的包含 dG Bind 属性，以及 CSV 列映射；程序不补算缺失评分 |
| 看不到蛋白 | 检查文件是否含受体；导入同坐标系受体并选择正确结构 |
| 要求连接文件 | 启动本机服务并允许必要的本地网络连接；页面会自动发现当前会话 |
| PowerShell 禁止运行脚本 | 可直接使用 `run.exe python3 ...` 命令；不需要永久更改系统执行策略 |
| 有互作统计但列表未收窄 | 查看“列表保留”及状态行；选择“具有互作”或快捷按钮，确认不是“仅统计” |
| 两个残基的结果比预想多 | 检查是否选了 OR；两者都必需时用 AND |
| 无互作不等于实验不结合 | 结果只反映当前姿态、当前结构与接口规则，不是实验结论 |
| 聚类与其他工作站不一致 | 核对骨架模式、Morgan 半径/位数/手性、分子预处理和聚类算法；不要只比较阈值数字 |

## 12. 开发验证与发布内容

```powershell
node scripts/test-analysis.mjs
npx tsc --noEmit
npm run build
```

研究项目专项验收脚本及真实数据不随 clean 源码发布；通用回归测试使用合成演示分子。原生计算需通过已安装 Schrödinger 的 Python 环境运行。

GitHub clean 版本包含应用源码、测试、依赖锁文件、浏览器化学引擎及第三方许可证；不包含研究项目、真实化合物文件、运行凭据、原始提交历史、node_modules 或构建缓存。独立部署不自动获得原在线工作台的私有访问权限，也不会自动同步其中的项目数据。

## 13. 分页与初筛候选清单（v12）

- 列表底部“每页显示”可选择 20、50 或 100 个分子；更换数量后返回第一页。
- 表头“当前页”复选框选择当前筛选、排序下的一页分子；全选后再次取消只移除这一页的选择；半选时可用底部“取消当前页选择”。部分入选时显示半选状态。
- 跨页选择、改变筛选和切换每页数量均保留既有候选；批量加入会跳过相同规范结构或超过自定义上限的记录，并显示提示。
- “候选清单”中的“候选数量上限”留空即不限；填写正整数即启用上限。降低上限不会删除已选记录，超限后需调整数量或移除候选才能继续加入。
- 候选上限和每页数量随项目保存。旧 Pocket Atlas 项目仍可打开，旧项目未提供上限时按不限处理，不再截断为 73 个。
- “初筛候选清单”用于人工初筛；CSV 导出包含全部已选候选，包括其他页面和当前分析范围外的候选。
